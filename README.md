# Word generator

This repo uses the N-Gram model to generate words based of training data. The original purpose of this repo was to create name generator for a game set in the pacific ocean, with procedurally generated islands. For this reason, many examples in this repo are of polonesian languages found in the pacific.

## Setup

Copy .env.example file and remove ".example".
Requirements are:
- python-dotenv
- pypdf (used only in data parsers)

## Generator

Words are generated based on data in ngram files, found in Source/ngrams directory. Ngram files are generated from wordlist training data in Source/wordlists. Word lists are generated by parsing raw data such as language data dumps and online dictionaries.

### Parsing raw data

The `maori_wordlist.txt` wordlist is generated using Maori_toraw.py script. It uses the dictionary found [here](https://kevindonnelly.org.uk/maori/downloads/dictionary.pdf)

The `polishPlaces_wordlist.txt` wordlist is generated using the Polish_toraw.py script. It uses a exhaustive database of polish place names. The data is divided into 5 pdfs found [here](https://www.gov.pl/web/mswia/wykaz-urzedowych-nazw-miejscowosci-i-ich-czesci)

Every other wordlist uses the wiktionary data dump found [here](kaikki.org/dictionary/rawdata.html). The wordlists are created using the `wiktJsonParser.py` script, with the options to choose which languages to create wordlists of. There are some settings in the code that change what words are accepted into the wordlist.

### Generating N-Grams and custom words
The `word_generator.py` script takes a wordlist file and generates an ngram file. Settings can also be found in the code. The `ngram_generator.py` script takes a ngram file and generates a list of custom words.

> Raw data was not commited into this repo. If you wish to use the parsers, the data has to be downloaded manually
